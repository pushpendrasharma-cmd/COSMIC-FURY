# 🚀 Cosmic Fury - Space Shooter

A fast-paced, neon cyberpunk arcade space shooter built with HTML5 Canvas, Web Audio API, and vanilla JavaScript.

![Cosmic Fury](https://img.shields.io/badge/Status-Complete-brightgreen)
![License](https://img.shields.io/badge/License-MIT-blue)

---

## 🎮 How to Play

- **Move (Side-to-Side)**: `A` / `D` or `Left Arrow` / `Right Arrow` (or Mouse Steering)
- **Fire**: `Space` or `Left Click` (Hold to fire, or toggle Auto-Fire in Settings)
- **Warp Dash / Dodge Roll**: `Shift` or `Right Click` (Grants invulnerability frames and ghost trails)
- **Overdrive / Fury Mode**: `F` (Unleashes 2.5x fire rate, wing-mounted micro-missiles, golden aura, and damage resistance)
- **Switch Weapons**: `Q` / `E` or click on weapon hotbar
- **Special Abilities**: `1` to `4` (EMP Bomb, Slow Motion, Mega Laser, etc.)

---

## ✨ Features

- **Fluid Controls**: Pure side-to-side tactical movement with dynamic ship banking tilt and mouse cursor steering.
- **Warp Dash**: Tactical evasive dodge with invulnerability frames and ghost afterimages.
- **Overdrive Mode**: Cosmic fury meter that charges with kills, boss fights, and high-risk projectile graze maneuvers.
- **Arsenal of Weapons**:
  - ⚡ **Laser Cannon**: Rapid-fire energy beams.
  - 💠 **Plasma Spreader**: High-spread tri-shot burst.
  - 🚀 **Homing Missiles**: Heat-seeking explosive projectiles.
  - 🔫 **Railgun**: High-damage piercing beams.
  - 🌀 **Vortex Cannon**: Gravitational singularity pulling nearby enemies.
  - ⚡ **Arc Lightning**: Chain-reaction electric arcs leaping between targets.
- **Dynamic Procedural Audio**: 100% Web Audio API synthesizer for retro space SFX and dynamic soundtrack.
- **Crisp High-DPI Rendering**: Dynamic Retina / 4K canvas scaling.
- **Progression & Customization**: Pilot profiles, skins, tech tree upgrades, achievements, and local leaderboards.

## 🛠️ Local Development

Open `index.html` in any modern web browser or serve locally:

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```

Visit `http://localhost:8080` in your browser.
